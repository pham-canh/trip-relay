The trip assistant

An assistant that asks before it shares

It is an agent network published as plain JSON and run by your own browser: a front agent that plans the trip and a fare agent that works this page. Harbor Hotel's concierge joins only after you say yes.

  • Works the page, not your account Four site actions, each marked read, write or irreversible in code. The model cannot change the marks, and it never sees the passenger.
  • Waits for you on anything final Booking is irreversible, so the runtime shows the action and its arguments and waits. A proposal made on stale data is refused.
  • Asks before it talks to anyone else Harbor Hotel is the only partner the airline may call. Every contact needs your approval, and only the request text crosses.

Questions

Before you let it talk to a hotel

Short answers here. The full pattern, threat model and limitations are in the protocol notes.

Is Skyline Air a real airline?
No. Skyline Air and Harbor Hotel are fictional, every flight and room is generated, and no payment or reservation is ever made. They exist to show one thing well: an agent that asks before it hands anything to another site.
What exactly does Harbor Hotel receive?
Only the request text you saw on the consent card and approved. Not your chat, not the passenger details, not the booking reference, not your router key. The hotel network then runs in your browser and its answer comes back as untrusted text.
Do I need an API key?
No. The assistant starts on a scripted demo model that runs in your tab with no network calls, and goes through the same consent gate as a real model. To try a real model, add an Otari key (or any OpenAI-compatible router) under Settings in the assistant.
What happens if the assistant tries to share my email?
The runtime checks the outgoing request before the consent card is even shown. Email addresses, phone numbers, card numbers, keys, the booking reference and encoded copies of them are stopped there, and the block is written to the receipt.
Are the two sites really separate?
The two sites run as independent origins: Skyline Air here, Harbor Hotel on its own host. The browser enforces true cross-origin sandboxing.
